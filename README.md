# finalproject

This repository contains my final project for BST260 (Fall 2026).

The project includes two analyses using public health datasets:

1. **Background-check laws and firearm deaths:** Examining whether restrictive state background-check laws are associated with changes in firearm death rates using RAND firearm legislation data and CDC mortality data.

2. **Outbreak severity by transmission mode:** Exploring whether foodborne, waterborne, and person-to-person outbreaks differ in hospitalization rates using CDC outbreak data.

The project includes data cleaning, descriptive statistics, statistical analyses, and visualizations. Results and limitations will be documented in separate vignettes.
